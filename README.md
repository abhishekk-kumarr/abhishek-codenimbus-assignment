# Front-End Developer Intern Assignment — Code Nimbus Solutions

## Overview
This project is a front-end recreation of the assigned wedding invitation website home page, built as part of the Front-End Developer Intern application process for Code Nimbus Solutions.

## Objective
Recreate the provided website's home page as accurately as possible, focusing on:
- Visual accuracy of elements
- Overall theme and design fidelity
- Animations and interactions
- Desktop screen size layout

## Tech Stack
- React.js
- CSS

## Getting Started

### Prerequisites
- Node.js installed

### Installation
```bash
git clone <repo-link>
cd <project-folder>
npm install
npm run dev
